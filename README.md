# CamGenerator - Fusion 360 凸轮生成器

一个 Autodesk Fusion 360 插件，用于自动创建盘形凸轮（Plate Cam）。

## 功能特性

- **参数化运动规律生成** — 通过基圆半径、升程角、运动规律等参数自动生成凸轮轮廓
- **导入轮廓点数据** — 从 CSV 文件读取角度-半径数据，样条拟合生成凸轮
- **三种运动规律** — 简谐运动、等速运动、改进梯形（分段加速度曲线，适合高速凸轮）
- **STEP 导出** — 创建完成后可选导出为 STEP 格式文件

## 安装方法

1. 下载或 clone 本仓库
2. 将整个 `CamGenerator` 文件夹复制到 Fusion 360 插件目录：

```
Windows: %APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\
macOS:   ~/Library/Application Support/Autodesk/Autodesk Fusion 360/API/AddIns/
```

3. 打开 Fusion 360，进入 **工具 > 附加模块**
4. 找到 **Cam Generator**，点击加载
5. 在 SOLID 工具栏的 **创建** 面板中会出现 **凸轮生成器** 按钮

## 使用方法

### 模式一：参数化运动规律

选择此模式后，设置以下参数：

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 运动规律 | 简谐运动 / 等速运动 / 改进梯形 | 简谐运动 |
| 基圆半径 | 凸轮最小半径 | 30 mm |
| 最大升程 | 从动件最大位移 | 20 mm |
| 近休止角 | 起始静止角度 | 30° |
| 升程角 | 上升段角度 | 120° |
| 远休止角 | 顶部静止角度 | 60° |
| 回程角 | 下降段角度 | 120° |
| 凸轮厚度 | 拉伸厚度 | 10 mm |
| 轴孔直径 | 中心孔直径 | 10 mm |

> 四个角度之和必须等于 360°

### 模式二：导入轮廓点数据

准备一个 CSV 文件，每行包含两个值：`角度(度),半径(mm)`，例如：

```csv
0,30
90,50
180,30
270,30
```

在输入框中填入 CSV 文件的完整路径，点击确定即可生成凸轮。

示例文件见 `examples/sample_cam.csv`。

## 运动规律说明

| 运动规律 | 特点 | 适用场景 |
|----------|------|----------|
| 简谐运动 | 加速度按余弦规律变化，启停平稳 | 中低速凸轮 |
| 等速运动 | 从动件匀速运动，启停有冲击 | 低速、需要匀速输出 |
| 改进梯形 | 分段加速度曲线，峰值加速度小 | 高速凸轮 |

- Python 3.x（Fusion 360 内置）
